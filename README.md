The make.fun Tiny Chess challenge calls for a chess engine in at most 4,096 bytes of Python 3.13.

## Run it

Once `main.py` is implemented, the grader supplies `MAKEFUN_ENV_URL` and runs the engine with this command.

```sh
python3 -P -s /bot/main.py
```
